## How to get added

1. Fork the repository and create a feature branch.
2. Make your change, keeping commits focused.
3. Open a pull request. CI (see [`.github/workflows/ci.yml`](.github/workflows/ci.yml)) must pass.
4. In the same PR, append your name to the **Contributors** list above in the form:
   `- Your Name <you@example.com> — short description of contribution`
